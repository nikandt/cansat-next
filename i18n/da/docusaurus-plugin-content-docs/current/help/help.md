# Hjælp med at forbedre oversættelser

Dette site bruger **maskinoversættelse** til ikke-engelske sprog. Selvom vi har gjort vores bedste for at bevare nøjagtighed og klarhed, kan der stadig være nogle fejl eller akavede formuleringer.

Hvis du ser noget, der ikke giver mening på dit sprog – eller hvis du gerne vil hjælpe med at forbedre en hel sektion – vil vi være meget taknemmelige.

## Sådan kan du hjælpe

Du kan bidrage på flere måder:

- 📝 **Rapportér problemer** direkte via e-mail: [support@kitsat.fi](mailto:support@kitsat.fi)
- 🌍 **Foreslå bedre oversættelser** ved at pege på den engelske kilde og den forbedrede lokale version
- 🔧 **Deltag i oversættelsesprojektet** – kontakt os, så giver vi dig adgang til vores oversættelsesfiler

## Tekniske detaljer

Oversættelser håndteres via [Docusaurus i18n-systemet](https://docusaurus.io/docs/i18n/introduction) og genereres ved hjælp af GPT-4. Du kan hjælpe ved at redigere `.json`- og `.md`-oversættelsesfiler i GitHub eller foreslå forbedrede formuleringer.

---

Tak fordi du hjælper os med at gøre dette projekt mere tilgængeligt og tydeligt for alle!
